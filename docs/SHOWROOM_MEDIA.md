These are photographs/renders of the actual bike at successive azimuth angles, not a flat CSS rotation and not free-orbit 3D geometry. Asset optimization preserves the original transparency and product appearance.

Each source prefix has `1.png` through `36.png`. Local files use `01.webp` through `36.webp`, beneath `public/assets/turntables/`, retaining source resolution up to 1000×700 pixels and WebP quality 86. Manufacturer ownership is retained; this provenance record does not assert an open-source asset license. No paid TORQEN source or assets are used.

Add a complete sequence and an exact existing catalogue colour to `SHOWROOM_MEDIA` to enable another model/finish. Asset integrity tests verify every mapped frame is present. All unmapped bikes/finishes keep their existing catalogue photograph with an explicit Photo View label and no rotation controls.

The existing illustrative catalogue values are read unchanged; manufacturer media does not update prices, stock, years, variants or specifications.
